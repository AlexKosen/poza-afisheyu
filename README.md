# Поза афішею

Статична онлайн-платформа про сучасний незалежний театр Києва.

## Запуск локально

Відкрийте `index.html` у браузері або запустіть простий статичний сервер у корені проєкту.

## Публікація

Сайт розрахований на GitHub Pages із кореня гілки `main`. У налаштуваннях репозиторію виберіть **Settings → Pages → Deploy from a branch → main → /(root)**.
